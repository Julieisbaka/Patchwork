# Credits

Some of Patchwork's hostile-mob behavior ideas were inspired by
[Mob AI Tweaks](https://modrinth.com/mod/mob-ai-tweaks) by JLekro, including
boss-oriented elder guardians, zombie riders and leaders, jump-enhanced witch
combat, longer-range pillager attacks, and homing blue wither skulls. Patchwork
implements its own versions of these ideas and does not include code or assets
from Mob AI Tweaks.
